# ODIN Travel - один шаг до идеального отеля

ИИ-консьерж для выбора отеля и планирования поездки. Локальный запуск, без передачи данных наружу.

## Быстрый старт

1. **Двойной клик** на `start.cmd` (Windows).
2. Подождите ~3 секунды — откроется браузер на http://localhost:8081.
3. Демо-аккаунт: `demo@odin.travel` / `odin-demo-2026`.

Требования: Go 1.22+ (или папка `C:\HACKATHONS\tools\go`).

## Ручной запуск

```bash
# Сборка
go build -o odin.exe .

# Запуск
set ODIN_DB_PATH=odin.db
set PORT=8081
set ODIN_OPEN_BROWSER=false
odin.exe
```

Откройте http://localhost:8081 в браузере.

## Структура проекта

- `main.go` — HTTP-сервер и API
- `store.go` — база данных и запросы
- `trip.go` — планировщик поездок
- `walk.go` — оптимизация маршрутов (2-opt)
- `attractions.go` — POI данные
- `poi_coords.go` — координаты достопримечательностей
- `match.go` — алгоритм совпадения отеля
- `assistant.go` — ИИ-консьерж
- `index.html` — главная страница
- `assets/` — CSS, JS, шрифты, изображения

## Функции

- Поиск отелей с фильтрами
- ИИ-подбор с пояснением причин
- Планировщик поездки (маршрут по дням)
- Пешеходные маршруты с оптимизацией
- Бронирование с демо-оплатой
- Избранное и история поездок
- Что если? — пересчёт при изменении параметров
