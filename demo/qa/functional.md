## 1. Цифры

Формула цены за ночь везде одна: `total = price + round(12% price) + round(5% price) + 900 * N`.
Вся путаница в том, что `N` берётся из РАЗНЫХ источников:

| Где | Чему равно N | Файл:функция |
| --- | --- | --- |
| карточка в `/api/search`, `plan.hotel` | `hotel.Capacity` (вместимость отеля, у всех 4) | `store.go:837` Search → `buildPriceBreakdown(hotel.PriceFrom, hotel.Capacity)` |
| `/api/hotels/{slug}` верхний `priceBreakdown` | `guests` из запроса | `store.go:905` HotelBySlug |
| `/api/hotels/{slug}` `rooms[].priceBreakdown` | `room.Capacity` | `store.go:975` rooms() |
| what-if `price/total` | `guests` из запроса | `whatif.go:133` nightTotal |
| UI `fullNightTotal`, `priceBreakdownFor`, `audit.js:breakdownForRoom` | число гостей в форме | `app.js:117/127`, `audit.js:27` |
| бронь на сервере и в UI | завтрака/налогов нет вообще | `store.go:1260` `total := price * nights`; `app.js:bookingTotal` |
