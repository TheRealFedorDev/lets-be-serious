## 1. Упала сеть

**Признак:** страница не грузится, или погода и фото не появляются. Сервер при этом на `localhost` работает.

**Что делать:**
1. Проверить локальный сервер: `curl -s http://localhost:8081/api/health`. Если отвечает, сервер жив, сеть не нужна для основного демо.
2. Переключиться на локальный адрес: все ссылки в демо ведут на `localhost:8081`, интернет не нужен.
3. Если не открывается даже `localhost`, перейти к разделу 2 (сервер).
4. Если упала и локальная страница: переключиться на видео из раздела 4.

**Что проверено:** демо-сценарии отдаются с сервера. Погода в плане взята из демо-данных (`/api/demo/scenario/{id}`). `[проверить: фото отелей и иконки подгружаются только из `/assets/`, без внешних CDN].`

## 2. Упал сервер

**Признак:** `localhost:8081` не отвечает, или `/api/health` выдаёт ошибку.

**Что делать:**
1. Посмотреть ошибку в терминале, где был запущен сервер.
2. Перезапустить той же командой:
   ```bash
   cd "/Users/aleksandraneev/Desktop/о остров"
   ODIN_DB_PATH="$PWD/odin.db" PORT=8081 go run .
   ```
3. Если порт занят (старый процесс): найти и закрыть его командой `lsof -i :8081`, затем перезапустить.
4. Если база недоступна или повреждена: запустить на копии БД `ODIN_DB_PATH="$PWD/odin-demo-backup.db"`. Этот файл заранее скопировать из `odin.db` `[проверить: сделать копию до демо]`.
5. Если сервер не поднимается за 2 минуты: переходить к видео (раздел 4). Не тратить время сцены на отладку.

## 3. Не работает ИИ-консьерж

**Признак:** в консьерже ошибка или пустой ответ. Статус `GET /api/assistant/status` показывает `"state":"fallback"`.

**Текущее состояние:** локальная модель не запущена (`local model server not found`). Консьерж работает на правилах. Это штатный путь, а не сбой.

**Что делать:**
- Не показывать ИИ-консьерж как главную функцию. В демо ключевой путь без ИИ: сценарий «Семья» → паспорт → «Что если» → маршрут → публичная страница.
- Если кто-то из жюри спросит про ИИ, сказать честно: «модель подключается локально, сейчас в демо работает запасной путь на правилах».
- Не говорить «ИИ работает», если статус `fallback`.

**Важно:** все три демо-сценария (семья, романтика, разумно) работают без ИИ. Проверено по API: `GET /api/demo/scenario/{id}` отдаёт план без обращения к модели.

## 4. Заранее записанное видео

**Что записать:** ролик 60–90 с по `demo/video-script.md`. Экспорт в MP4 по инструкции в том же файле.

**Куда сохранить:** `demo/video/odin-demo-1440.mp4` (папку создать вручную, если её нет).

**Статус:** видео ещё не записано. Записать до выхода на сцену. Без записи этот план работает только для разделов 1–3.

**Как запустить на сцене:**
1. Открыть файл двойным кликом, полноэкранный режим (Cmd+Ctrl+F).
2. Проверить звук и громкость до выступления.
3. Держать ссылку на видео в закладке, если сцена на другом устройстве.

## 5. Что мешает демо и как обойти

| Проблема | Обход |
|---|---|
| «Перестроить день» не отвечает `[проверить]` | Показать только таймлайн и погоду, сказать «пересчёт по дням». Или пропустить шаг. |
| «Что если» по бюджету даёт балл 100 без изменения | Не показывать вариант «+20% к бюджету». Показать «Добавить завтрак» и «+2 ночи», там цена меняется. |
| Карточка отеля показывает 110 952, план 114 552 | Говорить по плану (184 152). Не сравнивать с карточкой на сцене. |
| Мобильная ширина 360: кнопки планировщика не находятся | Демо вести на 1440×900. Мобильную версию не показывать. |
