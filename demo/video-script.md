# ODIN Travel — сценарий видео (60–90 с)

Формат: экранная запись Chrome 1440×900, голос за кадром на русском. Сценарий основан на демо «Семья» (Сочи, 18–22 ноя). Цифры из API на 2026-10-28, см. `demo/scenarios.md`.

Итог хронометража: 80 секунд, с запасом до 90.

## Чек-лист записи на macOS

### Подготовка окружения
- [ ] Запустить сервер: `cd "/Users/aleksandraneev/Desktop/о остров" && ODIN_DB_PATH="$PWD/odin.db" PORT=8081 go run .`
- [ ] Проверить `http://localhost:8081/api/health`: `status: ok`.
- [ ] Открыть Chrome, окно ровно 1440×900. Проверить `resize_window` или DevTools → Device Mode `[проверить]`.
- [ ] Закрыть все вкладки, кроме нужной. Панель закладок скрыть (Cmd+Shift+B).
- [ ] Выключить тёмную тему на Mac для ровного фона (или записывать в светлой).

### Уведомления и звук
- [ ] Включить «Не беспокоить»: Control Center → Focus → «Не беспокоить».
- [ ] Отключить уведомления от Chrome и мессенджеров.
- [ ] Звук системы выключить, если не нужна фонография.

### Офлайн-проверка
- [ ] Прогнать сценарий «Семья» целиком до записи, без ошибок в консоли (Cmd+Option+J).
- [ ] Проверить, что страница маршрута открывается при отключённом интернете (Wi-Fi off, сервер локальный) `[проверить: погода и фото могут идти извне]`.
- [ ] Проверить, что QR выводится без сети `[проверить]`.

### Запись (Cmd+Shift+5)
- [ ] Нажать Cmd+Shift+5, выбрать «Записать выбранную часть» (Record Selected Portion).
- [ ] Выделить область ровно 1440×900 в логических точках. На Retina это 2880×1800 пикселей; при экспорте уменьшить до 1440×900.
- [ ] Включить «Показывать касания» не нужно, курсор хватает.
- [ ] Вариант микрофона: «Встроенный микрофон» для голоса за кадром либо записывать голос отдельно в Voice Memos и сводить позже.
- [ ] Нажать «Записать», дать 2 секунды тишины в начале.

### Экспорт в MP4
- [ ] macOS пишет `.mov` по умолчанию. Конвертировать:
  `ffmpeg -i "входной.mov" -vf "scale=1440:900" -c:v libx264 -pix_fmt yuv420p -crf 20 -an "demo/video/odin-demo-1440.mp4"`
  (`-an` убирает звук; если голос записан вместе, убрать `-an` и добавить `-c:a aac`.)
- [ ] Проверить длительность: `ffprobe -v error -show_entries format=duration -of csv=p=0 файл.mp4` должно быть 60–90.
- [ ] Посмотреть финальный файл полностью, без пропусков кадров.
- [ ] Сохранить копию в `demo/video/` (папку создать вручную, если её нет `[проверить]`).
